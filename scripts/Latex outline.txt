\begin{frame}{What is Analysis of Covariance (ANCOVA)}
    \begin{itemize}
        \item ANCOVA is a general linear model that blends ANOVA and regression
        \begin{itemize}
            \item Most similar to MLR with categorical and continuous variables, but with different use cases
        \end{itemize}
        \item Generally used to compare group means after controlling for a nuisance variable (covariate)
        \item For example: in a randomized trial, treatment group might be a categorical variable and ANCOVA could be used to test the group means between treatment groups after controlling for age.
    \end{itemize}
\end{frame}

\begin{frame}{What is Analysis of Covariance (ANCOVA)}
    \begin{itemize}
        \item Their explanation: “ANCOVA analysis helps to find out how a variable, called covariate, affects model prediction success on a continuous dependent variable with grouping based on a categorical independent variable.”
        \item Their purpose: “After obtaining regression results, variables that are likely to be covariants were checked with ANCOVA.”
        \item R package: \textit{jmv}
    \end{itemize}
\end{frame}

\begin{frame}{Method Description}
    \begin{itemize}
        \item Dichotomized self-compassion due to near uniform distribution (when discarding lazy answers)
        \item Variables included in the model: worry, apathetic, self-compassion, curious, fear of harm from others, avoidance, compassion fatigue, dissociation, perception, mental wellbeing, depression, receptive, connectedness
        \item Results (finding \rightarrow conclusion):
        \begin{itemize}
            \item All the variables except worry and perception have a p-value below 0.05 \rightarrow it’s the right choice to include these variables in the regression model
            \item Self-compassion and compassion fatigue have statistically significant p values \rightarrow compassion fatigue is a covariate for the predictor categorical variable self-compassion within our linear model
        \end{itemize}
    \end{itemize}
\end{frame}
